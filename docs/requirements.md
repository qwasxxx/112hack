## Нефункциональные требования

| ID | P | Требование и статус | Проверяемый критерий |
| --- | --- | --- | --- |
| NFR-01 | P0 | **Реализовано:** локальный демонстрационный запуск | `docker compose up --build`, UI на `5173`, health сервисов отвечает |
| NFR-02 | P0 | **Реализовано:** работа без облака для основного голосового пути | Docker использует локальные T-one, llama.cpp/Qwen и Silero; внешний скоринг опционален |
| NFR-03 | P1 | **Частично:** устойчивость к отказу TTS/оценки | текстовый сценарий продолжается; отказ STT/LLM блокирует голосовой путь и должен быть показан пользователю |
| NFR-04 | P0 | **Реализовано частично:** сохранность учебных данных | Postgres volume и ежедневный JSON-снимок; автоматическое восстановление отсутствует |
| NFR-05 | P0 | **Не реализовано для недоверенной сети:** защита доступа | API не проверяет сессию и роль; стенд допустим только в доверенной локальной среде |
| NFR-06 | P1 | **Не подтверждено:** 20 одновременных LLM-сессий | нужен согласованный профиль нагрузки и тест на целевом оборудовании |
| NFR-07 | P1 | **Цель требует согласования:** задержка ответа и доступность | определить SLI/SLO и измерить на стенде; не назначать число без данных |

## Ограничения и допущения

- Демонстрация идёт на одном компьютере или в доверенной учебной локальной сети.
- Браузер поддерживает Web Audio, WebSocket, IndexedDB и разрешение микрофона.
- Модели уже загружены либо при первом запуске есть интернет.
- Тестовые данные не являются реальными персональными данными.
- Актуальный официальный файл ТЗ в репозитории отсутствует; доступна только сверка от 21.09.2026. Поэтому источник заказчика помечен как косвенный.
