# 002. Modular monolith

## Context

Есть realtime voice, AI orchestration, RAG, две роли. Искушение — сразу нарезать api / realtime / ai.

## Decision

Один NestJS-процесс. Bounded contexts — модули. AI и realtime — инфраструктурные модули, не отдельные сервисы.

## Alternatives

Микросервисы и отдельный AI-сервис изолируют нагрузку, но создают рассинхрон scenario state (прямо запрещённый риск) и лишний hop в STT→LLM→TTS. Для команды из нескольких людей это операционная сложность без выигрыша на хакатоне и раннем production.

Выделение сервиса позже: модуль + порты уже задают границу.

## Consequences

Горизонтальное масштабирование пока = несколько инстансов + позже Redis pub/sub. Сейчас достаточно одного процесса.
