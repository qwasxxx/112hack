# sys112-trainer

Учебный тренажёр операторов Системы-112. Прототип воспроизводит приём вызова в браузере, заполнение карточки происшествия, передачу сведений дежурно-диспетчерским службам (ДДС), разбор результата, наблюдение преподавателя и администрирование локального учебного контура.

Документ предназначен разработчикам и демонстрационной команде. Состояние документации сверено с веткой `codex/integrate-teacher-panel` на 24 сентября 2026 года. Незакоммиченные изменения пользователя не являются частью подтверждённого базового состояния.

## Быстрый старт

Для демонстрационного запуска нужен Docker Desktop, доступ в интернет при первой загрузке образов и моделей и ориентировочно 8 ГБ оперативной памяти.

```powershell
git clone https://github.com/qwasxxx/112hack.git
cd 112hack
docker compose up --build
```

Откройте <http://localhost:5173>. Все роли доступны в одном веб-приложении:

| Роль | Логин | Пароль |
| --- | --- | --- |
| Студент | `smirnova` | `112` |
| Преподаватель | `petrov` | `112` |
| Администратор | `volkova` | `112` |

Для остановки:

```powershell
docker compose down
```

Первый запуск загружает модель распознавания T-one, GGUF-модель Qwen и Silero TTS. Модели сохраняются в `models/`, данные PostgreSQL — в Docker volume `sys112-pgdata`. Основание: `infra/docker/docker-compose.yml`, `infra/docker/Dockerfile.models`.

## Проверка демонстрации

1. Откройте две вкладки на `http://localhost:5173`.
2. Войдите как `smirnova` в первой вкладке и как `petrov` во второй.
3. У преподавателя назначьте билет и запустите занятие.
4. У студента откройте назначенный сценарий, примите вызов, разрешите микрофон, задайте вопросы и заполните карточку.
5. У преподавателя убедитесь, что отображается присутствие и прогресс; отправьте подсказку.
6. Завершите звонок и проверьте разбор, запись занятия и комментарий преподавателя.

Подробный сценарий и диагностические развилки: [docs/development.md](docs/development.md) и [docs/operations.md](docs/operations.md).

## Состав системы

- `apps/student-web` — фактическое единое SPA для студента, преподавателя и администратора; роль выбирается после входа.
- `apps/api` — NestJS API, PostgreSQL-доступ, health-check, резервные копии и часть realtime-контура.
- `apps/stt` — FastAPI/WebSocket-сервис локального распознавания речи T-one.
- `apps/llm` — FastAPI/WebSocket-менеджер диалога; базовая версия работает с локальным llama.cpp.
- `apps/tts` — FastAPI-сервис синтеза речи; Docker-конфигурация использует Silero.
- `packages/shared-types`, `packages/api-client`, `packages/ui` — общие типы, клиент и UI-примитивы.
- `infra/database/migrations` — источник истины по схеме PostgreSQL.

`apps/teacher-web` и `apps/admin-web` существуют и собираются как отдельные SPA, но основной демонстрационный путь их не использует. Основание: `apps/student-web/src/app.tsx`, `apps/student-web/Dockerfile`, `infra/docker/docker-compose.yml`.

## Локальная разработка

Нужны Node.js 20+, pnpm 10 и Python 3.11; PostgreSQL можно поднять через Docker.

```powershell
pnpm install
.\scripts\setup-postgres.ps1
pnpm dev:api
pnpm dev:stt
pnpm dev:llm
pnpm dev:tts
pnpm dev:student
```

Адреса по умолчанию: веб-интерфейс `5173`, API `3000`, STT `8090`, llama.cpp `8080`, LLM manager `8091`, TTS `8092`, PostgreSQL host port `5435`. Полный перечень переменных приведён в `.env.example`; реальные ключи в репозиторий добавлять нельзя.

## Известные ограничения

Это хакатонный локальный прототип, а не боевой контур 112. В нём нет SIP/АТС, HTTPS, промышленной аутентификации и авторизации API, подтверждённой нагрузки на 20 одновременных диалогов, полного восстановления из backup и формальной OpenAPI-спецификации. Детали и приоритеты: [docs/limitations.md](docs/limitations.md).
